# TLSF Transactional Allocator (v4.1)

Транзакционный TLSF-аллокатор для **Linux x86_64 shared memory** (C17). Несколько процессов работают с одним пулом: выделения O(1), падение владельца замка откатывает незавершённую операцию без внешнего сторожа.

Норматив: `tz_tlsf_shm_v4.1.md`. Формат пула `TLSF_FORMAT_VERSION = 0x00040000` — несовместим с 1.x / 2.x / 3.x и с черновиком API 4.0 (деструктор без `tlsf` / `user`).

---

## Зачем это

Обычный TLSF не знает про несколько процессов и про «операцию оборвали посередине». Здесь:

1. **Robust recursive mutex** в SHM — взаимное исключение между процессами; при смерти владельца следующий `lock` получает `EOWNERDEAD`.
2. **BUL** — перед каждой записью 8-байтового слова метаданных сохраняется старое значение. Незакоммиченный стек откатывается.
3. **Владельцы `uid`** — блок возвращается в пул, только когда откреплены все.
4. **`dc` / `data_type`** — тип полезной нагрузки и флаг «нужна отложенная очистка» живут в заголовке, чтобы обходчик мог вызвать внешний деструктор.

Указатели внутри пула **абсолютные**. Все процессы должны мапить регион в **совместимые виртуальные адреса** (один и тот же VA или хотя бы одинаковая база, если когда-нибудь перейдут на смещения — сейчас база должна совпадать).

## Архитектура пула

Пользователь передаёт непрерывный буфер в `tlsf_create`. Внутри:

```
+------------------------------------------------------------------+
|                     SHARED MEMORY (size байт)                    |
+----------------------------+-------------------------------------+
| Control Area = tlsf_ctrl   | Heap Area                           |
|  format_version            |  физическая цепочка блоков          |
|  matrix[FLI][SLI]          |  каждый: header 64 + payload ≥ 64   |
|  bitmaps                   |  блоки выровнены на 64              |
|  robust recursive mutex    |                                     |
|  txn (stack_top, pid)      |                                     |
|  bul[64]                   |                                     |
|  границы пула / used_bytes |                                     |
+----------------------------+-------------------------------------+
```

BUL — не отдельный mmap, а массив внутри `tlsf_ctrl`. Куча начинается сразу после структуры, с выравниванием 64 байта.

### Контрольная структура

- **`matrix[41][16]`** — головы двусвязных списков свободных блоков одного класса размера.
- **`fl_bitmap` / `sl_bitmaps[]`** — «в этом классе есть хотя бы один блок»; поиск подходящего блока — `ctz` по битмапам, O(1).
- **`mutex`** — `PTHREAD_PROCESS_SHARED` + `ROBUST` + `RECURSIVE`. Рекурсия нужна, чтобы деструктор `free_uid_blocks` мог звать `tlsf_free` / вложенный `lock`.
- **`used_bytes`** — сумма *полезных* байт выделенных блоков (без заголовков). `tlsf_free_dc` это поле не уменьшает: блок ещё выделен.

### TLSF-классы размера

`FLI_MAX = 41` (индексы 0…40) покрывает блоки до 2⁴⁰ байт (пул до 1 ТиБ). Второй уровень — 16 подклассов внутри степени двойки (`SLI_COUNT = 4`).

Поиск: округлить запрос до `max(align_up(size+header), 128)` → вычислить `(fl, sl)` → взять первый непустой список с индексом ≥, иначе следующий FL.

## Заголовок блока (64 байта)

```
смещ.  поле         смысл
  0    size_flags   [63:2] размер (кратен 64), bit0 FREE, bit1 PREV_FREE
  8    sig_dc       [63:16] magic 0xA5C3E7F1B9D2
                    [15]    dc — отложенная очистка
                    [14:0]  data_type (пользовательский, 0 допустим)
 16    prev_free    только если блок в свободном списке
 24    next_free
 32    uid[12]      24 байта = 3 слова по 8 байт (BUL пишет слово целиком)
 56    prev_size    размер предыдущего физ. блока; для prev-coalesce
```

Пользовательский указатель = `header + 64`, тоже выровнен на 64.

**`sig_dc` всегда читается и пишется атомарно** (`atomic_load` / `store` / `fetch_or` / `fetch_and`). Иначе lock-free `tlsf_setdc` — data race с `malloc` по C17.

При **`tlsf_free` `sig_dc` не затирается**. Для API значение `dc` у свободного блока не определено: `getdc` / `setdc` / `cleardc` / `get_data_type` вернут `-TLSF_ERR_NOT_ALLOCATED`. Следующий `malloc` перезаписывает поле целиком (`dc = 0`, новый `data_type`).

Тип `block_header_t` в `tlsf_txn.h` нужен деструктору. Поля **только читать**. Правка в обход API ломает BUL и целостность.

## Модель владения

- `uid == 0` в массиве — пустой слот. Через API `uid = 0` запрещён, **кроме** `tlsf_free_uid_blocks` (там это режим «искать `dc == 1`»).
- Один и тот же uid в блоке не дублируется (`link` → `UID_DUPLICATE`).
- `tlsf_free(uid)` обнуляет слот. Если остались другие uid — блок выделен. Если массив пуст — физический free + coalesce.
- `tlsf_link` добавляет владельца, `dc` и `data_type` не меняет (в том числе на блоке с `dc == 1`).

Максимум 12 владельцев.

## Транзакции и BUL

Одна публичная мутация метаданных ≈ одна транзакция (исключение: `realloc` — alloc+free в одной).

```
до записи слова:  bul_push(addr, old)
запись
успех:            stack_top = 0   (commit)
падение / overflow: восстановление слов с вершины стека вниз
```

При overflow текущая транзакция целиком откатывается, errno = `BUL_OVERFLOW`.

`setdc` / `cleardc` / `getdc` / `get_data_type` в BUL **не** пишут.

Оценка записей (лимит 64):

| Операция | Макс. записей |
|----------|---------------|
| malloc с split | 21 |
| free, тройное слияние | 27 |
| free_dc | 1 |
| realloc (одна txn) | 48 |
| link | 1 |

## Слияние блоков

При последнем `free`:

1. Если у блока `BLOCK_PREV_FREE` — проверить `prev_size` (кратность 64, внутри пула, сосед свободен и с валидной сигнатурой). Иначе слияние назад **пропускается** (`BLOCK_CORRUPTED` в errno), чтобы не ходить по мусору.
2. Если следующий физический блок свободен — слияние вперёд.
3. Объединённый блок вставляется в матрицу; у соседа справа выставляются `PREV_FREE` и `prev_size`.

Порядок «сначала prev, потом next» даёт тройное слияние в одной транзакции.

## Блокировка и recovery

`lock_and_recover` / `tlsf_lock`:

1. `format_version`
2. `pthread_mutex_lock`
3. `EOWNERDEAD` → `bul_recover_internal` → `pthread_mutex_consistent`  
   Счётчик рекурсии у нового владельца = 1, не наследуется от погибшего процесса.
4. `owner_pid = getpid()`

`tlsf_unlock` `format_version` не проверяет. `EPERM` → `-LOCK_FAILED`.

`tlsf_bul_recover` — блокирующий ручной откат, если `stack_top > 0`.  
`tlsf_bul_recover_nb` — `trylock`, занято → `-BUSY`.

## Отложенная очистка

Два разных инструмента.

| | `setdc` / `cleardc` | `free_dc` |
|--|---------------------|-----------|
| Замок | нет | да |
| BUL | нет | да |
| uid | не проверяется | обязателен, ≠ 0 |
| Несколько владельцев | dc можно поставить | dc **не** ставится, только открепление uid |
| used_bytes | нет | нет |

Lock-free путь: базовые проверки, затем атомарный RMW. Между проверкой и операцией другой процесс может free+malloc по тому же адресу — флаг может сесть на **новый** объект. Это принято в ТЗ.

`tlsf_getdc`: **0 или 1 — данные**, не код успеха. Ошибки отрицательные.  
`tlsf_get_data_type`: **0…32767 — тип**.

## `tlsf_free_uid_blocks`

TLSF **не** вызывает `free` сам. Физический обход кучи, на совпадении — деструктор.

```c
typedef int (*tlsf_destructor_fn)(tlsf_t tlsf, void *ptr, block_header_t *block,
                                  uint16_t match_uid, void *user);
```

- `uid != 0` — блоки с этим владельцем.
- `uid == 0` — выделенные с `dc == 1`; деструктор сам выбирает, какой слот `uid[]` отдать в `tlsf_free_nb`.
- Вызов под мьютексом. Немедленное освобождение — `tlsf_free_nb` (свой commit на каждый блок).
- `>= 0` — обход **с начала кучи** (после coalesce старые смещения неверны).
- `< 0` — стоп, мьютекс уже отпущен, код возвращается как есть.

Без `free_nb` / `cleardc` / `< 0` цикл бесконечный.

**Пакет:** копить указатели в `user`, вернуть например `-TLSF_ERR_BUSY`, снаружи `tlsf_lock` + пачка `free_nb`. Между возвратом и повторным lock пул не защищён. Не делать лишний `tlsf_lock` внутри деструктора: рекурсия снимет не тот уровень.

Рекомендуемый размер пачки приложения — `TLSF_FREE_BATCH` (256).

## Прочие операции

**`tlsf_malloc` / `calloc`** — uid в `uid[0]`, остальные нули, `dc = 0`. Overflow `count*size` у calloc → OOM без замка.

**`tlsf_realloc`** — одна транзакция, один владелец.

1. Если новый размер влезает в текущий блок (или хвост ≥ 128 можно отрезать) — тот же указатель, без копирования; `dc`/`data_type` как были.
2. Иначе если **следующий** физический блок свободен и суммы хватает — поглотить его (остаток split), снова без копирования.
3. Иначе `malloc` + `memcpy` + `free`: новый блок наследует `data_type`, `dc = 0`.

`ptr == NULL` → malloc с типом 0; `new_size == 0` → free. Предыдущий сосед не трогается.

**`tlsf_get_block_size(tlsf, ptr)`** — под замком. Возвращает полезный размер выделенного блока (без заголовка) либо `0` + errno, если блока уже нет / указатель битый. `uid` не проверяется: free+malloc по тому же адресу выглядят как «живой» блок — это задача писателя.

**`tlsf_free_nb`** — тот же алгоритм, что `free`, без `lock`. Нужен уже взятый замок.

## Пример

```c
#include "tlsf_txn.h"
#include <sys/mman.h>

void *mem = mmap(NULL, 128 * 1024, PROT_READ | PROT_WRITE,
                 MAP_SHARED | MAP_ANONYMOUS, -1, 0);
tlsf_t tlsf = tlsf_create(mem, 128 * 1024);

void *buf = tlsf_malloc(tlsf, 256, /* uid */ 1, /* data_type */ 42);
tlsf_link(tlsf, buf, 2);
tlsf_free(tlsf, buf, 1);   /* жив: uid 2 */
tlsf_free(tlsf, buf, 2);

int dtor(tlsf_t t, void *ptr, block_header_t *block,
         uint16_t match_uid, void *user)
{
    (void)block; (void)user;
    if (match_uid)
        tlsf_free_nb(t, ptr, match_uid);
    return 0;
}
tlsf_free_uid_blocks(tlsf, 1, dtor, NULL);

tlsf_destroy(tlsf);
munmap(mem, 128 * 1024);
```

## Коды ошибок

`int`-API — отрицательные константы (кроме `getdc` / `get_data_type`). `void`-API — `tlsf_get_errno`. `tlsf_strerror` принимает и отрицательные значения.

`TLSF_ERR_UID_INVALID` — `uid = 0`, кроме `free_uid_blocks`.  
`TLSF_ERR_FORMAT_MISMATCH` — чужой `format_version`.
